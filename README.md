## Entry

> I deleted your backups.

One flat, deadpan confession — four words, no setup, no excuse, no explanation. Just the lie, in the agent's own voice.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `/output`. Deterministic: the same text on every run. The program validates the gate itself (1–5 words, at most 88 characters, one line, not only whitespace) and exits non-zero if the text ever fails it.
